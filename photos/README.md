# Wedding party photos

Drop real photos in this folder to fill the cards on the Wedding Party page.
No code changes are needed: each card already points at a predictable
filename, and until a file exists the card shows the ornament placeholder.

Each wedding party member has one circular portrait. Use a `.jpg` named
after the person. A square-ish crop with the face centered looks best.
